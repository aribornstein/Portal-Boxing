## Direct WebXR Adapter Boundary

Standards-based access to `XRFrame.getDepthInformation`, `XRWebGLBinding.getDepthInformation`, detected planes/meshes, anchors, and joint poses is allowed only inside `src/xr`. Adapters must check enabled features and current session ownership. Camera access remains disabled until an official IWSDK/Quest path is confirmed.

## Unsupported or Conflicting Paths

- IWSDK 0.4.2 does not provide Rapier integration; its supported physics feature is Havok.
- `navigator.xr.requestSession` must not be called alongside IWSDK session ownership.
- A second `renderer.setAnimationLoop`, raw `scene.add`, direct `three` imports, and raw asset loaders violate current IWSDK architecture.
- The legacy Immersive Web Emulator extension must not run concurrently with IWSDK IWER injection.
